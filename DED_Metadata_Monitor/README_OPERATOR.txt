DED Metadata Monitor - first prototype

How to use
1. Double-click run_ded_metadata_monitor.bat.
2. Click Register sample when a physical DED sample is produced.
3. Fill the sample-level production metadata:
   - Sample ID
   - Laser power
   - Scan speed
   - Powder rate
   Sample ID is auto-generated by default. Uncheck Auto if you need to type it manually.
4. Optional sample-level fields can be filled when known:
   - Argon rate
   - Substrate temperature
   - Operator
   - Shielding / powder lot / nozzle / substrate prep / surface notes
5. Put new DED raw data files into DED_Data_Inbox.
6. Wait a few seconds for the registration window.
7. Select one detected file from the file list.
8. Pick the file type and choose the registered sample this raw file belongs to.
9. Add file-specific notes if needed.
10. Click Save metadata for this file.
11. Completed files turn green. Files still missing metadata stay red.
12. Repeat until every file is green.
13. Click Register completed files.

Browse registered files
- The right side of the main window shows the current Library structure.
- Raw files are grouped by Sample ID and file type.
- Derived results are shown under each Sample ID in the derived_results group.
- Select a raw file or derived result to view its metadata.
- Use Open file, Open folder, or Copy path to access the registered file.
- If a derived result is selected, these buttons use its linked source raw file.

Add derived results
- Use Add derived result for values extracted from registered raw files.
- Examples: melt pool width, bead height, dilution, porosity, hardness, UTS, or yield strength.
- Choose the Sample ID and, when possible, the source raw file that the value came from.
- Add one or more metric rows with metric name, value, and unit.

Where files go
- Registered files are moved to DED_Data_Library\runs\<sample_id>\.
- The searchable metadata is saved in:
  - DED_Data_Library\metadata.sqlite
  - DED_Data_Library\runs.csv
  - DED_Data_Library\files.csv
  - DED_Data_Library\derived_results.csv
  - DED_Data_Library\derived_results.xlsx

Notes
- Treat files inside DED_Data_Library as read-only archive files.
- If a registered file needs to change, put the changed file back into DED_Data_Inbox and register it as a new version/new entry.
- Beam profile CSV files are registered as beam_profile_csv.
- Optical microscope cross-section images are registered as melt_pool_section_image or beam_section_image.
- If you cancel registration, files stay in DED_Data_Inbox.
