FSW Metadata Monitor - first prototype

How to use
1. Double-click run_fsw_metadata_monitor.bat.
2. Click Register sample when a physical FSW sample is produced.
3. Fill the sample-level production metadata:
   - Sample ID
   - Rotation speed (rpm)
   - Travel speed (mm/min)
   - Tool ID
   - Material
   - Thickness (mm)
   Sample ID is auto-generated by default. Uncheck Auto if you need to type it manually.
4. Put new FSW raw data files into FSW_Data_Inbox.
5. Wait a few seconds for the registration window.
6. Select one detected file from the file list.
7. Pick the file type and choose the registered sample this raw file belongs to.
8. Add file-specific notes if needed.
9. Click Save metadata for this file.
10. Completed files turn green. Files still missing metadata stay red.
11. Repeat until every file is green.
12. Click Register completed files.

Browse registered files
- The right side of the main window shows the current Library structure.
- Raw files are grouped by Sample ID and file type.
- Derived results are shown under each Sample ID in the derived_results group.
- Select a raw file or derived result to view its metadata.
- Use Open file, Open folder, or Copy path to access the registered file.
- If a derived result is selected, these buttons use its linked source raw file.

Add derived results
- Use Add derived result for values extracted from registered raw files.
- Examples: defect area, tunnel defect size, mean force, peak temperature, UTS, yield strength, or hardness.
- Choose the Sample ID and, when possible, the source raw file that the value came from.
- Add one or more metric rows with metric name, value, and unit.

Where files go
- Registered files are moved to FSW_Data_Library\runs\<sample_id>\.
- The searchable metadata is saved in:
  - FSW_Data_Library\metadata.sqlite
  - FSW_Data_Library\runs.csv
  - FSW_Data_Library\files.csv
  - FSW_Data_Library\derived_results.csv
  - FSW_Data_Library\derived_results.xlsx

Notes
- Treat files inside FSW_Data_Library as read-only archive files.
- If a registered file needs to change, put the changed file back into FSW_Data_Inbox and register it as a new version/new entry.
- If a file is unrelated, select file type = unrelated.
- If clamping, backing, cooling, tool wear, or surface condition changed,
  select changed and describe it in Anything unusual.
- If you cancel registration, files stay in FSW_Data_Inbox.
